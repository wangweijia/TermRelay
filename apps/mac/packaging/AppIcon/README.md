# TermRelay macOS App Icon V2

This directory owns the macOS release artwork. The app is built with SwiftPM, not an Xcode project.
The repository's `scripts/build-mac-release.sh` uses `TermRelay-AppIcon-1024.png` to build the app bundle icon.

The complete macOS icon matrix is included: 16, 32, 64, 128, 256, 512, and 1024 pixels.
`AppIcon.appiconset` and the previews are retained alongside the master export.
