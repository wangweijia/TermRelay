验收专用 Chrome

在验收者电脑上使用独立的 Chrome 用户配置，不安装 ZeroOmega；日常用户配置中的代理设置保持不变。

首次使用：创建专用用户配置
  1. 点击 Chrome 右上角头像，添加用户配置，选择不登录账号继续，命名为“项目验收”。
  2. 在新用户配置中安装点点改，打开本设置页，粘贴开发者发来的配对配置。
  3. 业务系统在此用户配置中单独登录；以后从“项目验收”进入。

普通新窗口或新标签页不会隔离代理设置。插件不会自动创建用户配置，也无法确认当前是否为专用配置。

代理方式

ZeroOmega 快速配置

只新增一个代理情景和两条优先规则，不导入整份备份，也不覆盖现有规则。更换开发者 Mac 地址后需更新。

先保存 App 配对配置，即可生成当前环境的配置方案。

通常不需要填写。只有无法复制完整配置时，才使用下面的手动方式。不要填写 AI API Key 或管理密钥。

ZeroOmega 模式下，结束连接会撤销本次代理认证并关闭已有预览隧道，但不会修改 ZeroOmega。若需移除分流，请在 ZeroOmega 中停用新增规则。

整个 App 同时只允许一个插件实例连接，同一 Chrome 用户配置的多个页面可共用。切换验收者时请结束连接；浏览器异常退出后约 90 秒释放。
