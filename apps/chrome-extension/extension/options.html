高级设置与连接诊断

通常不需要填写。只有无法复制完整配置时，才使用下面的手动方式。不要填写 AI API Key 或管理密钥。

ZeroOmega 模式下，结束连接会撤销本次代理认证并关闭已有预览隧道，但不会修改 ZeroOmega。若需移除分流，请在 ZeroOmega 中停用新增规则。

整个 App 同时只允许一个插件实例连接，同一 Chrome 用户配置的多个页面可共用。切换验收者时请结束连接；浏览器异常退出后约 90 秒释放。
